Restaurant Chatbot Application
============================

****
1. Extract XAMPP Portable to a folder (app folder)
2. Navigate to the htdocs folder within the extracted XAMPP directory
3. Create a new folder called restaurant_chatbot (copy this folder into htdocs)
4. Copy your PHP files, HTML, and JavaScript into this folder
****


Instructions:
1. Double-click "Start_Restaurant_Chatbot.bat" to launch the application
2. Wait for the services to start (about 10 seconds)
3. The application will open in your default web browser
4. To stop the application, close the command prompt window
